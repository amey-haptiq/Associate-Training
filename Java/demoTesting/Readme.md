 Blog API - Spring Boot Project

A simple RESTful Blog API built with **Spring Boot**, demonstrating standard CRUD operations using:
- Spring Data JPA
- H2 (in-memory) database
- Spring Security (optional)
- JUnit 5 and Mockito for testing



 Tech Stack

- Java 17+
- Spring Boot
- Spring Web
- Spring Data JPA
- H2 Database
- JUnit 5
- Mockito
- Spring Boot Test (`@MockBean` for mocking)
