# 🛡️ Secure Blog API with JWT Authentication (Spring Boot)

A secure REST API built with **Spring Boot** that uses **JWT (JSON Web Tokens)** for authentication and authorization. It includes:

- User Registration and Login
- Token-based access with JWT
- Role-based authorization
- CRUD operations on blog posts
- Spring Security configuration
- Secure API endpoints with protected routes

---

## 🚀 Features

- 🔐 JWT Token-based Authentication (`/auth/login`, `/auth/register`)
- 🧾 Role-based Authorization (`ROLE_USER`, `ROLE_ADMIN`)
- 📝 Blog CRUD:
    - Create, Read, Update, Delete posts
- ⚙️ Custom Security Configuration
- 🧪 Ready for unit & integration testing

---

## 🔧 Tech Stack

- Java 17+
- Spring Boot 3.x
- Spring Security
- Spring Web
- Spring Data JPA
- H2 Database (or switchable to MySQL/PostgreSQL)
- JWT (via `io.jsonwebtoken.Jwts`)
- Maven / Gradle
